Bugs found by simulation

GH-001 fixed seed 3

Double execution when the verification probe is also lost. The executor guards a lost ACK by probing the service. The probe has its own failure mode — when the network dropped both, an empty health response failed the guard and control fell through to retry.

Fix: the probe returns a tristate and retries with backoff. An unobservable state now fails closed. “Cannot observe” must never collapse into “did not happen”.

181 occurrences in 15,000 runs (~1.2%)

GH-002 fixed critical seed 149

Client-side idempotency cannot protect an involution. rollback_version applied twice returns to the starting version. A network-duplicated request left the service back on the bad version — indistinguishable, from the client, from never having run.

Fix: the server honours Idempotency-Key. Client-side keys are necessary but not sufficient; at-most-once requires server participation. This is why Stripe and AWS put idempotency server-side.

95 occurrences in 100,000 runs (~0.1%)
